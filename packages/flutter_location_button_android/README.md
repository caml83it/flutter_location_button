# flutter_location_button_android

The Android implementation of [`flutter_location_button`](https://github.com/caml83it/flutter_location_button).

## Features

- Uses the official Android 17+ `androidx.core.locationbutton.LocationButton` system-trusted button.
- Grants one-time / session-scoped precise location authorization without a standard system permission dialog.
- Graceful runtime permission fallback for earlier Android versions.
- Supports customizable background color, foreground/tint color, corner radius, and system button text labels.
